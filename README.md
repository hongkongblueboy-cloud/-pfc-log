# PFC Log

カロリーとPFC(タンパク質・脂質・炭水化物)を1行入力で記録するトラッカー。

**公開URL**: https://hongkongblueboy-cloud.github.io/-pfc-log/

## 使い方

`サトウ 270k p4 c61` のように「品名 カロリー p タンパク質 f 脂質 c 炭水化物」の形式で入力して送信する。
順不同で書けて、省略した項目は0として扱う。カロリーを省略した場合はPFCから概算する(表示に `*` が付く)。

- **倍率**: 送信ボタン左のピルから0.1〜3.0を指定すると、4つの値すべてに倍率をかけて記録する(半分だけ食べた場合など)
- **最近の食品**: 入力欄の下のチップをタップすると、前回の値がそのまま入力される
- **KPI**: ヘッダー右上から1日の目標値を変更できる
- **バックアップ**: KPI設定内の「データ」から記録の書き出し・読み込みができる

## データの保存場所

記録は開いた端末のブラウザ内(localStorage)にのみ保存される。サーバーには送られないため、
端末が変わると引き継がれない。移行するときはバックアップの書き出し・読み込みを使う。

## 構成

`index.html` の1ファイルのみ。GitHub Pages(mainブランチのルート)から配信している。
